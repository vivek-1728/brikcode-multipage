# BRIKCODE website
Static site: HTML, vanilla CSS, vanilla JS. Open index.html or serve the folder.
- Nav and footer are injected by js/script.js (edit them there).
- Replace placeholders: [Add email], [Add phone], [Add location], [Add careers email], [LinkedIn URL], [GitHub URL].
- The contact form does not send yet. Connect it to a backend or form service in js/script.js.
- assets/logo-icon.png is also used as favicon.
